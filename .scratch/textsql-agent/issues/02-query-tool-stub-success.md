# 02: 查数工具一次（内部全替身）走通

**What to build:** 用户问数时，主 Agent 写出当前问题并调查数工具一次。工具内部用替身跑完工作流，返回有行结果；主 Agent 用人话回复；上次 SQL 与四项摘要成对落盘。同一句再调第二次被拒绝。

**Blocked by:** 01 环 A 一轮能说话

**Status:** done（「四项摘要」已被 ADR 0002 改成自由文本摘要，见下方注）

- [x] 一句问数的用户话会调查数工具恰好 1 次，入参是当前问题而不是必须等于用户原话的口语指代句
- [x] 工具回填有行结果后，用户收到人话回复，回复中的数来自回填而不是主 Agent 编的
- [x] 查库成功后上次 SQL 与四项摘要（指标、时间、过滤、口径）成对覆盖；程序槽不经主 Agent 传入
- [x] 同一句用户话里第二次调查数工具被拒绝或次数仍为 1
- [x] 环 A 用例仍保持查数工具次数为 0

---

**注（ADR 0002 之后）**：文中的「四项摘要（指标、时间、过滤、口径）」现在是单值的自由文本 `query_summary: str | None`。「成对覆盖」这条行为没变。见 `../../../docs/adr/0002-free-text-summary-and-clean-src.md`。
