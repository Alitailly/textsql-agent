# 06: 查库对话真只读跑 SQL

**What to build:** 查数工具内部的查库对话用只读工具跑 SQL。有行则成功回填；0 行说没查到并覆盖两槽；报错或超时在对话内改 SQL 再跑；次数用尽则槽不动并丢掉这次查库对话。系统不因 0 行自动再调查数工具。

**Blocked by:** 05 Vanna RAG 只检索一次

**Status:** done

- [x] 有行：查数工具回填 SQL 与截断结果（最多 50 行或约 4000 字），两槽成对覆盖，查库对话被丢掉
- [x] 0 行：对人说没查到，两槽仍覆盖为这次空查询，本轮查数工具仍只有 1 次
- [x] SQL 报错或超时计入只读调用，对话内可再跑；每段查库对话最多 5 次，单次超时 30 秒
- [x] 5 次用尽仍失败：回填最后 SQL 与报错，两槽保持旧值，本轮摘要扔掉，查库对话被丢掉
- [x] 查库大模型只有只读查库工具，不能问用户、不能再检索、不能联网搜索
